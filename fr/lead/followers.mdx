Être leader est gratuit, pour autant de comptes que vous voulez. Les followers voient votre taux de réussite et votre nombre de trades, jamais votre solde ni votre historique de trades. Vous voyez leur prénom et leur initiale.

</Frame>

## Partager votre ID de suivi

Chaque compte depuis lequel vous êtes leader a son propre ID de suivi, listé sous **Vos ID de suivi** dans **Followers**. Cliquez sur le bouton copier pour copier l'ID, ou sur **Partager** pour copier une phrase qui explique comment vous suivre.

Un compte qui copie un trader n'est pas listé : un compte est leader ou follower, pas les deux.

**Ce que voient les followers** montre les chiffres que reçoivent vos followers.

## Répondre aux demandes

Les demandes s'affichent sous **En attente de votre réponse**. Les demandes sans réponse expirent après 7 jours.

- **Accepter** : le follower peut copier le compte à partir de maintenant.
- **Refuser** : le follower ne copiera pas le compte. Il pourra redemander après 7 jours.

## Retirer un follower

Sous **Vos followers**, cliquez sur **Retirer**, puis sur **Retirer le follower**. Il arrête aussitôt de copier le compte. Les trades déjà ouverts de son côté restent ouverts.
