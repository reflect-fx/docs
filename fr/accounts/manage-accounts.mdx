**Comptes** range vos comptes par rôle :

- **Sources** : leurs trades sont copiés.
- **Copieurs** : ils reçoivent des copies. La colonne **Licence** indique si chacun a une licence.
- **Inutilisés** : aucune copie ne les utilise encore.

Cliquez sur un compte pour ouvrir son détail.

<Frame>
  ![Le détail d'un compte](/images/fr/account-panel.jpg)
</Frame>

| Section | Ce qu'elle montre |
|---|---|
| **Solde** | Le solde lu chez le broker. Cliquez sur **Actualiser** s'il affiche **Indisponible**. |
| **Que doit faire ce compte ?** | Sur un compte inutilisé : choisissez s'il copie ou s'il est leader. |
| **Licence** | Sur un copieur : s'il a une licence. |
| **ID de suivi** | Sur une source ou un compte inutilisé : l'ID que d'autres collent pour demander à le copier. Cliquez sur **Partager l'ID de suivi** pour copier une phrase prête à envoyer. |
| **Copies vers ce compte** / **Copies depuis ce compte** | Les copies qu'il reçoit ou dont il est la source, avec leur taille et leur état. |
| **30 derniers jours** | Ses trades clôturés des 30 derniers jours. |
| **Proxy** | Comptes cTrader seulement. Voir [Trader depuis une IP dédiée](/fr/accounts/proxy). |
| **Rôle** | **En faire un follower** clôt ses demandes de suivi et supprime les copies dont il est leader : ses followers cessent de le copier. **En faire un leader** arrête et supprime ses copies, et sa licence, s'il en a une, revient dans votre plan. Les trades ouverts restent ouverts. Un compte est leader ou follower, pas les deux. |
| **Groupes** | Les groupes du compte. |

## Groupes

Un groupe rassemble des comptes pour les retrouver. Un compte peut être dans plusieurs groupes. Cliquez sur le bouton dossier à côté de **Relier un compte** pour créer, renommer ou supprimer des groupes. Supprimer un groupe supprime aussi ses comptes qui ne sont dans aucun autre groupe. Utilisez **Tous les groupes** pour n'afficher qu'un groupe.

## Reconnecter un compte

Quand la connexion au broker prend fin, le compte affiche **À reconnecter**. Cliquez sur **Reconnecter** et connectez-vous à nouveau pour continuer à copier.

## Supprimer un compte

Dans le détail du compte, cliquez sur **Supprimer ce compte**, tapez l'identifiant pour confirmer et cliquez sur **Supprimer le compte**.

- Sa connexion au broker disparaît, ainsi que chaque copie arrêtée qui l'utilise, y compris celles de vos followers.
- Les copies encore en cours sur ce compte doivent d'abord être arrêtées.
- Les positions chez votre broker restent ouvertes.

C'est définitif.
